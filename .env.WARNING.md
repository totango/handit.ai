# ⚠️ WARNING: PRODUCTION CREDENTIALS ⚠️

The `.env` files in this project contain **REAL PRODUCTION CREDENTIALS** for testing purposes.

## IMPORTANT:
1. **NEVER COMMIT** these .env files to version control
2. These credentials connect to **PRODUCTION DATABASES** and services
3. Be extremely careful when running migrations or making changes
4. The `.gitignore` file should already exclude `.env` files, but double-check

## What's Connected:
- **Database**: Production PostgreSQL database (handit database)
- **Redis**: Production Redis cache
- **Email**: Production SendGrid account
- **AI**: Production Bedrock/AI services

## Safe Testing:
To test safely without affecting production data:
1. Consider creating a separate test database
2. Use read-only queries when possible
3. Test write operations carefully
4. Monitor production logs while testing

## If You Need Local-Only Setup:
Replace the production values in `.env` with local ones:
```
TIMESERIES_DB_HOST=localhost
REDIS_URL=redis://localhost:6379
```

Then use `docker-compose -f docker-compose.dev.yml up db redis` to run local services.
